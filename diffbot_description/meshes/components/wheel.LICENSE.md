# wheel.stl: credit and terms

`wheel.stl` in this folder is the wheel model [Wheel D65x25](https://grabcad.com/library/wheel-d65x25-1) by **KlimukVI**, published on GrabCAD on 2019-05-08 as "Wheel D65x25 for Arduino car project". It's the wheel of DiffBot and Remo, converted to STL in metres, with the axle along z.

## Terms

The BSD 3-Clause licenses of the diffbot repository and of `diffbot_description` don't cover this file. GrabCAD's terms apply to it. GrabCAD's help article [How can models be used and shared?](https://help.grabcad.com/article/246-how-can-models-be-used-and-shared) says:

- Public use without any money changing hands, for example in a free CAD library, is covered if you credit the original creator and link to the model.
- Commercial use, such as selling the model or prints of it, needs the original designer's explicit permission.

If you share this file or a file made from it, keep this credit with it: the model's name, its creator KlimukVI and the link to the model. Ask the creator on GrabCAD before any commercial use.
